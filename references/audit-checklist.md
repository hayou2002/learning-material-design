# 学习材料审查清单

审查分三通道。不要用“排版看起来不错”代替内容与学习效果检查。

## A. 内容通道

- [ ] 学习结果可观察：读者能解释、比较、计算、判断、操作或产出什么。
- [ ] 读者、先备知识、使用场景和常见误区写清楚。
- [ ] 每个关键概念有定义、适用条件和一个具体正例。
- [ ] 容易混淆的概念有反例、边界例或对比。
- [ ] 事实、数字、引用和来源可追溯；没有编造研究结论。
- [ ] 没有把相关写成因果，也没有把个别案例写成普遍规律。
- [ ] 练习与目标一致，不是只考记忆或只做机械填空。
- [ ] 反馈解释原因和下一步检查点，不只给对错。
- [ ] 复习安排包含提取和间隔，不只写“回去复习”。
- [ ] 最后有迁移任务或真实任务，不只重复原例。

## B. 结构通道

- [ ] 全文一个中心问题，章节围绕读者任务展开。
- [ ] 先备知识在需要之前出现，没有突然引入未定义术语。
- [ ] 每节一个主要判断或任务；长节已拆分。
- [ ] 标题写问题或结论，读者只看标题能理解主线。
- [ ] 每节有结论、证据/例子、限制或行动。
- [ ] 关键概念后有小节、检查或练习；没有连续多页无停顿。
- [ ] 例子、反例、练习和迁移的顺序合理。
- [ ] 同一概念没有被无关故事、重复说明和装饰切片打散。
- [ ] 目录、编号、图表编号和交叉引用一致。
- [ ] 读者能在不打开外部链接的情况下理解主要内容。

## C. 表面通道

- [ ] 每页/每节有清楚的视觉入口，不靠读者自己找重点。
- [ ] 标题、正文、图注和练习题层级清楚。
- [ ] 字号、行距、行宽和段距适合阅读场景。
- [ ] 图、表和对应文字相邻；图有标题、单位、来源和替代文本。
- [ ] 练习有作答空间；答案没有提前泄露。
- [ ] 对比度足够；颜色不是唯一信息。
- [ ] 没有溢出、遮挡、乱码、孤行标题和图表断裂。
- [ ] Word/PDF 的目录、页码、题注和交叉引用可回读。
- [ ] PPT 一页一个判断，投影字号可读，缩略图节奏有变化。
- [ ] 长材料在打印、移动端或低质量投影下仍能读。

## 红旗

出现以下情况时，先停下来修内容或结构，不要继续美化：

- 读者读完不知道要做什么。
- 一节里出现多个新概念，且没有例子或检查。
- 只有结论，没有证据或适用条件。
- 练习答案就在题目旁边。
- 复习只是重读原文。
- 图表没有单位、来源或结论。
- 页面靠大量小字、边框和卡片制造“完整感”。
- 用“学习风格”解释读者差异。
- 关键数字或引用无法回溯。
- 只做了静态截图检查，没有实际打开/渲染成品。

## 交付判断

至少满足：

1. 内容通道没有未解决的红旗。
2. 结构通道能让目标读者按顺序完成一次学习任务。
3. 表面通道通过实际渲染/打开检查。
4. 事实、引用和练习反馈可追溯。
5. 未验证项明确报告，不把“看起来可以”写成“已验证”。

学习材料不是以“页数完成”为终点，而是以读者能完成目标、能提取、能迁移为终点。
