# 内容精加工

精加工不是把句子写漂亮，而是把“作者知道的内容”改造成“读者能理解、能练习、能迁移的路径”。

## 1. 先做诊断

拿到一份已有材料，先分四类问题：

| 问题 | 表现 | 先改什么 |
| --- | --- | --- |
| 目标不清 | 读完不知道要会什么 | 写可观察的学习结果 |
| 先备知识缺失 | 突然出现未定义术语、符号或步骤 | 补前置概念或预训练 |
| 结构过载 | 一段多个概念，章节按资料来源堆叠 | 切片、重排、加信号 |
| 缺少主动加工 | 只有解释，没有例子、反例、练习和反馈 | 加示例与提取题 |
| 版式造成负担 | 长墙文字、图不贴文、答案泄题、颜色过多 | 修版式和无障碍 |

先修目标、先备知识和结构，再修句子和版式。不要用排版掩盖内容问题。

## 2. 从材料中抽出概念

把原文中的：

- 定义
- 规则
- 步骤
- 条件
- 例外
- 数据
- 例子
- 引用

分别标出来。每个定义至少回答：

```text
它是什么？
它解决什么问题？
它在什么条件下成立？
它容易和什么混淆？
一个正例和一个反例是什么？
读者怎样检查自己真的懂了？
```

## 3. 把目录改成学习路径

专家目录常按知识分类，学习路径要按依赖关系。把：

```text
第一章 概念
第二章 方法
第三章 案例
```

改成：

```text
1. 先认识问题：为什么需要这个方法
2. 学会最小概念：它是什么，什么时候不适用
3. 看一个完整示范：每一步为什么这样做
4. 做半独立练习：填一个关键步骤
5. 独立解决一个变式：换条件
6. 回到真实任务：判断该不该用
```

每个标题尽量写成问题或结论，不要只写“概述”“相关分析”“其他内容”。

## 4. 一节的最小结构

除纯目录页外，一个概念/技能小节至少包含：

```text
本节要解决什么
→ 必要先备知识
→ 定义或规则
→ 正例
→ 反例或边界
→ 检查题
→ 解释性反馈
→ 一句小结
```

如果内容很长，拆成多个这样的小节；不要在一节里塞五个新概念。

## 5. 把解释改成可理解的顺序

优先顺序：

1. 具体场景或问题。
2. 读者已经知道的东西。
3. 新概念或规则。
4. 正例。
5. 反例/边界。
6. 检查题。
7. 小结与下一步。

抽象定义不要单独悬空。先给一个能触摸的例子，再抽象；或者先给抽象规则，再立即用例子落地。

## 6. 例子与反例

例子要满足：

- 真实或可信，不伪造数据。
- 只引入完成任务所需的变量。
- 明确哪些条件在起作用。
- 与读者的实际场景有连接。

反例要说明：

- 它为什么看起来像正例。
- 哪一个关键条件不满足。
- 如果条件改变，结论会不会改变。

对比示例只改变一个关键维度。否则读者无法判断差异来源。

## 7. 练习与反馈

每节至少一个提取题。题型按目标选择：

| 目标 | 题型 |
| --- | --- |
| 记住定义 | 用自己的话解释；给正例/反例判断 |
| 理解关系 | 画关系图；解释为什么 |
| 执行步骤 | 填空、排序、半独立操作 |
| 选择方法 | 给多个情境，判断该用哪种方法 |
| 迁移 | 换条件、换材料、换约束 |

反馈至少包含：

```text
答案
为什么
常见错误
下一次先检查什么
```

不要把答案直接放在题目旁边。需要开卷示例时，明确写“这是示范，不是测试”。

## 8. 复习与迁移

复习不是重复原文。把同一个概念安排成：

1. 当天：复述或解释。
2. 几天后：无提示提取。
3. 一周后：变式题。
4. 更晚：真实任务或跨情境迁移。

迁移任务要改变一个条件，让读者不能靠背原答案通过。例如：

- 换一个材料或数据源。
- 增加一个约束。
- 让一个常见捷径失效。
- 要求解释为什么方法仍然适用或不适用。

## 9. 已有材料的改写顺序

1. 保留原文事实和引用，先不改数字。
2. 标出每节的学习结果。
3. 找先备知识缺口，补最小解释。
4. 把长段拆成概念、例子、检查。
5. 删除重复和无关装饰。
6. 加提取题、反馈和迁移任务。
7. 最后才做版式。

不要用“润色”替换事实，也不要用“精简”删掉必要的边界和限制。

## 10. 反模式

- 标题全是名词，读完后不知道要做什么。
- 每段都很长，没有路标和小结。
- 只有定义，没有例子和反例。
- 只有例子，没有抽象规则，读者无法迁移。
- 练习答案就在题目下方。
- 复习只是“再看一遍”。
- 为了“高级感”加大量图标、渐变、卡片和动画。
- 把复杂内容拆得太碎，读者看不到整体关系。
- 用“学习风格”给读者贴标签。
