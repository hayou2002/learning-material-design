# 教育心理学参考

这份参考把有研究支持的原则转成材料设计动作。原则有适用条件，不能当成万能公式；具体材料仍要用真实读者和小规模试用来验证。来源选择、证据强弱和许可见 [证据来源与使用边界](evidence-sources.md)。

## 1. 认知负荷

认知负荷理论区分：

- **内在负荷**：任务本身的复杂度和元素之间的关联。
- **外在负荷**：材料组织、呈现方式和无关信息造成的额外负担。
- **生成性加工**：读者用来理解、组织和巩固知识的有效努力。

设计动作：

- 先教必要术语和符号，再给完整任务。
- 把复杂任务拆成有意义的片段，而不是按页数硬切。
- 删除装饰性信息、重复说明和与目标无关的背景。
- 让图、表、注释与对应文字靠近；在图上直接标注。
- 不要让屏幕上的全文与讲解逐字重复。

边界：降低外在负荷不等于删掉必要难度。复杂任务的内在负荷只能管理，不能假装不存在。

## 2. 多媒体学习

Mayer 的多媒体学习原则中，与材料设计最直接的有：

| 原则 | 设计动作 |
| --- | --- |
| 一致性 | 删除与学习目标无关的图片、故事、背景音乐和装饰 |
| 信号 | 用标题、粗体、箭头、路标和小结指出结构 |
| 冗余 | 避免同一内容同时以长篇文字和逐字讲解重复 |
| 空间邻近 | 图和对应文字放在同一视区 |
| 时间邻近 | 讲解和对应画面同步出现 |
| 分段 | 让读者控制节奏，一次处理一个片段 |
| 预训练 | 先介绍关键术语、部件和关系 |
| 个性化 | 用自然、面向读者的表达，不堆术语 |

边界：具体效果受材料、读者、媒介和测量方式影响，不能把每个原则都当成硬性分数。模态原则（用听觉代替屏幕文字）也不是任何场景都适用。

## 3. 例子、反例与专家反转

- 初学者从完整 worked example（完整示范）中获益，尤其是步骤多、问题结构不明显的任务。
- 随着熟练度提高，完整示范会变成冗余，应逐渐撤掉支架，转向独立练习。
- 抽象规则至少配一个正例；容易混淆时再配反例和边界例。
- 对比时只改变一个关键维度，否则读者无法判断差异来自哪里。
- 对程序性任务，可以把完整示范与独立解题交替安排，而不是先让读者看一大段示范再统一做题。

设计动作：示范 → 填空/半独立 → 独立任务 → 变式任务。不要让初学者直接“自己探索”，也不要把熟练者困在一步一步的示范里。

## 4. 具体与抽象表征

抽象定义、符号或公式要与具体例子、图形或情境建立明确对应。不要假设读者能自己看出二者关系。

设计动作：

- 用同一个例子贯穿“具体情境 → 图示 → 符号/规则”，逐一指出对应关系。
- 换一个表面情境再让读者判断，避免只记住例题措辞。
- 图形必须解释关键过程或关系；不是有图就算多表征。

## 4. 提取练习

测试效应表明，主动从记忆中提取信息通常比重复阅读更有利于长期保持。这里的“测试”不等于考试，可以是：

- 合上材料复述一个概念。
- 先写答案，再看解释。
- 用新例子判断规则是否适用。
- 解释为什么某个反例不成立。

设计动作：

- 为关键学习结果安排闭卷提取；频率按难度、先备知识和材料长度调整。
- 先给作答空间，再给答案和解释。
- 反馈说明“为什么对/为什么错”，不只给对错符号。
- 把错误当作诊断信息，记录错因和下次检查点。

## 6. 间隔练习

间隔效应表明，把学习分散到不同时间通常比一次性集中学习更有利于长期保持。间隔长度要按材料难度、保留期和读者时间安排调整。

设计动作：

- 同一概念在不同章节或不同日期再次出现，但不要简单重复原文。
- 第一次复习用提取题，第二次用变式题，第三次用迁移任务。
- 提供复习计划时写“复习什么、用什么题、间隔多久”，不只写“记得复习”。
- 对高风险考试或技能，间隔和提取优先于重读、划线和抄写。

## 7. 交错练习

交错练习把相关但不同的题型或概念混合出现。它可能让练习时的即时表现变差，但有助于训练“识别该用哪种方法”的能力。

适用条件：

- 读者已经建立基本区分。
- 题型或概念之间容易混淆。
- 目标是选择、判断或迁移，而不是刚学会单个步骤。

初学阶段先分组练习，建立基本规则；随后再交错。不要把交错当成一开始就混合所有难题。

注意：“示范与解题交替”不等于“不同题型交错”。前者用于建立程序，后者用于辨别和选择方法；不要混为一个固定模板。

## 8. 精细化提问与自我解释

让读者回答“为什么”“如果条件变了会怎样”“这一步和上一步是什么关系”，比被动阅读更能促进理解。

设计动作：

- 在关键步骤后加“为什么这一步成立？”
- 给一个条件变化，让读者预测结果。
- 让读者用自己的话解释图表或公式。
- 对错误解释给出针对性反馈，而不是只说“再想想”。

## 9. 元认知与自我调节

读者常常高估自己的掌握程度。材料应帮助他们校准：

- 练习前先估计把握，练习后对比实际结果。
- 让读者标记“确定 / 不确定 / 猜的”，再核对。
- 记录错因：概念不懂、条件看错、步骤遗漏、计算错误、表达不清。
- 给“下一次先检查什么”的具体提示。

计划、监控和评价要嵌入具体学科任务，不能只给一份脱离内容的“学习方法清单”。先用示范、提示卡或提问支架，再随能力增加撤掉。

## 10. 形成性反馈

反馈服务于“现在在哪、目标在哪、下一步怎么改”，不是只给分数或评价个人。

设计动作：

- 先确认读者理解任务目标和成功标准，再指出具体差距。
- 反馈聚焦任务、学科策略和自我调节，说明为什么错、如何修正。
- 给读者一次修改、重答或换例应用的机会；没有行动的反馈很难形成闭环。
- 控制反馈量，优先处理阻碍后续学习的误区。

边界：反馈并非越多越好，也不是任何反馈都有正效果。书面或口头只是载体，内容、时机和读者能否使用更重要。

## 11. 动机、相关性与自我效能

动机不是靠口号。材料可以通过以下方式支持投入：

- 开头说明“学这个能解决什么真实问题”。
- 任务难度略高于当前能力，但有支架和成功经验。
- 给读者选择顺序、例子或练习形式的有限空间。
- 反馈针对策略和过程，不贴“聪明/笨”的标签。
- 让读者看到自己的进步和可迁移性。

## 12. 通用学习设计（UDL）与无障碍

UDL 强调提供多种表征、行动表达和参与方式。落地时不是把同一内容做成三种重复版本，而是：

- 关键概念有文字解释，也有图、表或示例。
- 读者可以用文字、口头、图示或操作来展示理解。
- 材料有清楚的标题、目录、替代文本和足够对比度。
- 不依赖颜色、动画或单一感官传递关键信息。

无障碍检查借 WCAG 的可读性判据，但不宣称 Office 文件“符合 WCAG”。

## 13. 常见误区

| 误区 | 更准确的做法 |
| --- | --- |
| “视觉型/听觉型学习者要用不同教法” | 学习风格匹配缺乏稳定证据；用多种表征服务内容，不给读者贴标签 |
| “降低认知负荷就是越简单越好” | 删无关负荷，但保留必要难度和主动加工 |
| “看完了就是学会了” | 用提取、解释、变式和迁移任务验证 |
| “重复阅读最有效” | 重读可辅助，但长期保持通常不如提取和间隔练习 |
| “图越多越直观” | 图必须承担解释关系；装饰图会增加无关负荷 |
| “交错练习一开始就混着来” | 先建立基本区分，再混合易混题型 |
| “反馈只给对错” | 解释原因、指出策略和下一步检查点 |
| “固定 1/7/14/30 天就是科学复习法” | 间隔应按保留目标、难度和真实表现调整；日期只是可修改的起点 |
| “示范与解题交替等于题型交错” | 前者建立程序，后者训练辨别；目的和使用时机不同 |
| “元认知就是写学习心得” | 在具体任务中示范、练习计划—监控—评价，并逐步撤支架 |

## 14. 最小验证

材料结构通过审查不等于学习效果已验证。正式批量制作前，选一段代表性内容做小样本试用：

1. 记录读者能否说出目标、在哪卡住、是否误解示例。
2. 在间隔后做一次不看材料的提取或应用，不只看当场满意度。
3. 用错因修改解释、示范或练习，而不是只调整颜色和字号。
4. 有真实学习记录时，把结果交回 `wf-study` 调整后续计划；没有则明确“尚未验证学习效果”。
