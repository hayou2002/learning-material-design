# 证据来源与使用边界

本 Skill 用证据帮助做设计决定，不承诺“用了某原则就一定提分”。需要新原则时，先查下列来源，再补充适用对象、实施动作、反例和边界；不要只堆研究名词。

## 1. 来源优先级

| 优先级 | 来源 | 用来回答 | 使用限制 |
| --- | --- | --- | --- |
| 1 | IES/WWC 实践指南、EEF 指南与证据综述 | 哪些教学建议有综合证据，证据层级怎样 | 指南有发布年份、对象和学科范围；不把层级直接当效果保证 |
| 2 | 同行评议的系统综述、元分析、原始实验与权威著作 | 某机制为何成立、对谁有效、在什么条件下反转 | 单篇研究不替代综合证据；相关研究不写成因果 |
| 3 | 政府教育机构的教师指南、学科课程标准、专业组织规范 | 如何落地到学科、年龄、课堂与可访问性 | 地区制度和对象不同，不能直接外推 |
| 4 | 开放教材、大学开放课程 | 补充概念、术语、教学示例与延伸阅读 | 教材是二手解释；重要结论回到原始研究或指南 |
| 5 | GitHub 结构化知识库、社区技能与文章 | 发现关键词、候选模式和原始论文线索 | 不能因星数、格式或“AI 审核”而视为科学证据 |

## 3. 何时查 GitHub，怎样查

- 需要结构化术语、教学模式的多个候选或某原则的反向证据时，可查 Learning Design Wiki。
- 需要教材源稿时，优先官方组织自己的仓库，例如 OpenStax；不从转载站下载不明版本。
- 只读取与问题相关的条目，记录仓库、路径、访问日期、许可证和原始引用。禁止用 GitHub Topic 搜索结果充当研究结论。
- 社区 Agent Skill 可以帮助执行流程，但其内容仍需按上述优先级核验；本轮不安装或捆绑第三方 Skill。

## 4. 写入规则前，先填证据卡

```text
问题：这条规则要解决什么学习困难
来源：指南/综述/原始研究，标题、版本或年份、链接
适用：读者、学科、任务、媒介和先备知识
动作：材料具体怎样改
边界：何时无效、何时应撤掉、哪些证据仍不足
验证：用哪个可观察结果试用，怎样决定是否保留
许可：只链接、短引用、允许改编，还是禁止批量复制
```

只有观点或经验时标为“项目经验”，不包装成研究结论。不同来源冲突时保留条件和反例，不强行写成统一硬规则。

## 5. 持续更新

- 官方指南改版时更新版本和对应动作，保留仍有依据的旧原则，不盲目追新。
- 每季度或用户指出失效时复核常用入口；无需为每次材料制作重新做全量调研。
- 本文件只登记少量高价值入口。候选链接和单次研究放项目工作记录，不把 Skill 变成书签堆。
